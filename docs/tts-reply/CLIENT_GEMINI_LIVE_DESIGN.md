# アプリ内 Gemini — 設計と実装（2026-11-05 時点）

リングで話したら、Mac を通さずにアプリから直接 Gemini Live と会話し、返事を届いた端から再生する。コードの場所は [ARCHITECTURE.md](ARCHITECTURE.md) §2-2。

## 1. 使い方

1. Index 設定 → ボタン設定で、使う押し方（例：Hold & Talk）の行き先を **Gemini Live** にする。
2. その下に出る **Gemini API key** に Google の API キーを入れて **Save key**。
3. リングで長押しして話す。
4. 前の会話を忘れさせるときは **Reset conversation**。

返事は Index タブの Replies に、自分の発話と一緒に残る（あとから再生できる）。

## 2. 流れ

```text
リング ─(区切りごとに BLE)─▶ スマホ
   RingAudioTap：区切りを横から受け取り、音声に戻す（約 10 kHz・16bit）
   GeminiLiveStreamer：録音ごとにまとめる
   GeminiLiveResponder.respondToParts
     ├ 最初の区切り：Gemini のセッションを取る（事前接続済みならそれ）→ activityStart
     ├ 区切りが届くたびに：そのままのレートで audio を送る
     └ 最後の区切り（押し方が入っている）
          ├ 行き先が Gemini Live → activityEnd → 返事の音声を届いた分から再生 → ログと履歴に保存
          └ それ以外 → 返事を作らせずに切る
後から：録音処理の順番待ち → GeminiLiveRecordingOperation
     └ 転送の開始番号で流し込み済みを探す。答え済みなら何もしない。答えられていなければ保存済みの録音で答える
```

### 決めたこと

| 項目 | 決めたこと | 理由 |
|---|---|---|
| 区切りの受け取り方 | Haversine の公開項目 `environment.transferDelegate` を包む（元の処理を先に呼ぶ） | ライブラリは音声を転送完了時にしか外に出さない。ソースは非公開（GitHub は 404、Maven の sources.jar は空）で改造できない。Android・iOS とも同じ項目がある |
| 送るタイミング | 区切りが届いたらすぐ。最後の区切りから `activityEnd` まで実測0.02秒 | 待つ理由がない |
| 話し終わりの判断 | 自分で `activityStart`／`activityEnd` を送る（Gemini の自動の区切りはオフ） | リングの録音は終わりがはっきりしている。沈黙を待つより速い |
| 押し方が分からない間 | どれかの押し方が Gemini Live なら、1秒以上の録音はいったん全部送る。最後の区切りで行き先を見て、違えば返事を作らせない | 押し方は最後の区切りにしか入っていない |
| 前処理（雑音除去・音量） | 通さない | 録音処理の本体は変えない約束。Gemini は生の音声でも聞き取れている |
| 1秒未満の録音 | 送らない | ボタン操作。RingSync も同じ基準で捨てる |
| 押し方の判定 | 最初の長押しまでで決める（`RingGesture.forRecordingSequence`） | リングは長押し中に「長押し・短押し…」「長押し・長押し・長押し」などを報告する（2026-11-05 の17回中10回） |
| 失敗したとき | 返事が鳴り始める前の失敗なら、保存済みの録音で答え直す。鳴り始めた後なら、理由を返事ログに残す | 二重に鳴らさない |

## 3. 課金の安全策

| 場面 | 上限 |
|---|---|
| 事前接続（転送が始まったら先に開く） | 使われなければ30秒で閉じる |
| 初期設定の待ち | 2分 |
| 流し込み中 | 区切りが30秒来なければ閉じる |
| 返事の待ち | 2分 |
| やり直し | しない |

会話1回ごとにセッション1本で、返事が終わったら閉じる。

## 4. 実測（Android、moto g24、ボタンを離す→鳴り始め）

| 方式 | 結果 |
|---|---|
| 全部そろってから送る（流し込み前） | 6.0〜6.7秒 |
| 区切りを流し込む | 3.6〜5.3秒 |

流し込み方式の内訳：リングが送り始めるまで 0.9〜1.8秒、リングが送り終わるまで 1.5〜1.7秒、`activityEnd` まで 0.02秒、Gemini の最初の音声まで 1.0〜1.9秒。区切りが届き始める時刻は、リングがつながっているかどうかで変わる（17:09 は押している間から届き、17:38 の2回は離してから届いた）。つながり方はリングとライブラリが決めていて、理由はこちらでは確かめていない。

## 5. まだ確かめていないこと

- iPhone 実機（コンパイルは通る）。
- ロック中・画面を閉じた状態。
- 会話のリセット、キーの誤り（理由が返事ログに出るはず）。
- Gemini に時計も検索もつながっていない（時刻を聞くと間違える）。
